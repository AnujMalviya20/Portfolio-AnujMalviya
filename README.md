## 📖 Overview

This repository houses the source code for **Anuj Malviya's personal portfolio website**, engineered with a focus on high aesthetic quality, smooth micro-interactions, responsive architecture, and performance. 

The site serves as a central hub highlighting competitive hackathon achievements, published research, end-to-end data science projects, and technical proficiencies in Data Engineering, Machine Learning, and AI application development.

---

## ✨ Features

- **🎨 Modern Dark Aesthetic:** Built with a curated dark color palette, subtle glassmorphism effects, custom borders, and purple accent glow.
- **⚡ Blazing Fast Performance:** Powered by Vite 5 and React 18, bundling optimized production assets with sub-second page loads.
- **🪄 Cinematic Micro-Interactions:** Smooth typewriter effects, framer-motion scroll-triggered reveals, and cursor-responsive highlights.
- **🖼️ Interactive Hackathon Gallery & Lightbox:** Built-in modal lightbox for reviewing hackathon events, gallery photos, and conference presentations.
- **📊 Metric Cards & Stats:** Real-time summary of hackathon participations, award recognitions, research conferences, and active projects.
- **📱 Responsive & Mobile-First:** Fluid layouts meticulously tested across desktop, tablet, and mobile breakpoints.
- **📬 One-Click Connectivity:** Streamlined contact channels connecting directly to Email, LinkedIn, and GitHub.

## 🚀 Getting Started

To run this project locally, follow the steps below:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18.x or later is recommended).

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AnujMalviya20/Portfolio-AnujMalviya.git
   cd Portfolio-AnujMalviya
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Launch the development server:**
   ```bash
   npm run dev
   ```

4. **View in browser:**
   Open [http://localhost:5173](http://localhost:5173) to see your local instance.

---

## 📦 Build & Deployment

### Production Build

To create an optimized, minified production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Deploying to Cloudflare Pages (Live)

1. Connect your GitHub repository to [Cloudflare Pages](https://pages.cloudflare.com/).
2. Select **Vite** as the framework preset.
3. Configure the build settings:
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. Deploy! Your website will be available at your custom or `.pages.dev` subdomain.
